# data-audit — בדיקה, תיעוד וניקוי של קובצי נתונים מחקריים וארגוניים

**גרסה:** 18.11.2026 · **פיתוח:** ד"ר יצחק בנבניסטי, מכללת ספיר · **רישיון:** MIT (קוד), CC BY 4.0 (תיעוד ונתוני דוגמה)

> **English summary.** data-audit is a Claude Skill (with a ChatGPT version) that audits, documents and
> cleans research and organisational data files — surveys, HR/biographical records and sensor exports —
> and builds their data dictionary. It finds problems, shows the evidence and the options, and leaves every
> decision to the researcher; each change is saved as a new version, logged, and verified by code that did
> not make it. Download `data-audit-skill.zip` from the latest Release and upload it to Claude as a skill.
> Documentation is in Hebrew and English; reports can be produced in either language.

data-audit הוא Skill (כישור) ל-Claude, ולצדו גרסה מקבילה ל-ChatGPT, שמלווה את החוקר או החוקרת בבדיקה שיטתית של קובץ נתונים לפני הניתוח. הכלי אינו "רובוט ניקוי": הוא מאתר בעיות בקובץ, מציג לכל בעיה את הראיות שעליהן היא נשענת ואת החלופות לטיפול בה, ומשאיר את ההחלטה בידי החוקר. כל שינוי בנתונים נשמר כגרסה חדשה ונרשם ביומן, וכל גרסה נבדקת בקוד נפרד מזה שביצע את השינוי, כך שבסוף התהליך אפשר לשחזר ולהראות בדיוק מה נעשה בקובץ ומדוע.

הכלי מתאים לשלושה סוגי נתונים עיקריים: שאלונים וסקרים (כולל קובצי SPSS וייצוא מ-Qualtrics או Google Forms), רשומות ארגוניות וביוגרפיות (משאבי אנוש: תאריכי קליטה ועזיבה, דרגות, שכר, מבנה דיווח), ונתוני חיישנים וסדרות זמן (שעונים חכמים, אפליקציות, דגימות חוזרות). בין היתר הוא בודק כפילויות ומזהים סותרים, ערכים חריגים ובלתי אפשריים, קודים של ערכים חסרים (כמו 9 או 99) שנכנסו לחישוב כאילו היו תשובות, פריטים הפוכים שלא היפכו או שהיפכו פעמיים, מהימנות סולמות, דפוסי מענה רשלני, התאמה בין גלי מדידה, וחשיפה של מידע מזהה בשדות טקסט.

## הורדה והתקנה ב-Claude

1. בעמוד ה-Releases של המאגר (בצד ימין של העמוד הראשי), הורידו את הקובץ `data-audit-skill.zip` מהגרסה האחרונה.
2. ודאו שבהגדרות של Claude (Settings) מופעלת היכולת להריץ קוד וליצור קבצים (Code execution and file creation).
3. בהגדרות, באזור ה-Skills (כישורים), בחרו בהעלאת כישור והעלו את הקובץ `data-audit-skill.zip` כפי שהוא, בלי לפתוח אותו.
4. פתחו שיחה חדשה, צרפו את קובץ הנתונים וכתבו, למשל: "תבדוק את הקובץ הזה", "תבנה לי מילון נתונים" או "data audit".

בתחילת העבודה Claude ישאל באיזו שפה להפיק את הדוחות, מה ידוע לכם על הנתונים (האם יש שאלון, מילון משתנים, איזו עמודה היא המזהה) והיכן מותר לעבד אותם. מכאן העבודה מתקדמת בשלבים, ובכל נקודה שבה נדרשת החלטה מחקרית (למשל, האם להוציא משיב, כיצד לטפל בקוד חסר, האם פריט הפוך) הכלי יציג את האפשרויות וימתין לתשובה שלכם. כדי להתנסות לפני שעובדים על נתונים אמיתיים, אפשר להשתמש בקובץ הדוגמה שבתיקייה `examples/`.

## שימוש ב-ChatGPT

ההוראות המלאות נמצאות בקובץ `data-audit/references/chatgpt.md`. בקיצור: יוצרים Custom GPT, מדביקים את תוכן הקובץ `chatgpt/GPT_instructions.md` בשדה ההוראות (Instructions), מורידים מעמוד ה-Releases את `data-audit_chatgpt_knowledge.zip`, פותחים אותו ומעלים את הקבצים שבתוכו כקובצי ידע (Knowledge), ומפעילים את Code Interpreter. סביבת העבודה של ChatGPT מתאפסת בין שיחות, ולכן בסוף כל שיחה יש להוריד את תיקיית העבודה ואת הדוחות.

## פרטיות: לקרוא לפני שמעלים נתונים

כאשר משתמשים ב-Claude או ב-ChatGPT בדפדפן, הקבצים שמצורפים לשיחה מעובדים בשרתים של החברה המפעילה ולא במחשב שלכם. לכן, לפני העלאת קובץ, הסירו ממנו כל מידע מזהה (שמות, מספרי תעודת זהות, טלפונים, כתובות דואר אלקטרוני) או עבדו על עותק שעבר התממה, אלא אם נהלי המוסד ואישור ועדת האתיקה של המחקר מתירים אחרת. הכלי עצמו בודק אם בקובץ נותר מידע מזהה ומתריע על כך, אך הבדיקה הזו אינה מחליפה את האחריות שלכם. קובץ ששמו "אנונימי" אינו בהכרח אנונימי.

## מה מקבלים בסוף

קובץ נתונים נקי, מילון נתונים (codebook) מתועד, קובץ החלטות שמפרט כל בעיה שנמצאה ואת ההחלטה שהתקבלה לגביה, טבלת זרימת N (כמה משיבים נכנסו, כמה הוצאו ומאיזו סיבה), יומן שינויים מלא שממנו ניתן לשחזר כל גרסה, ותיאור טיוטה של שלב הכנת הנתונים לפרק השיטה, שבו כל מספר נלקח מן היומן ומה שהיומן אינו יכול לדעת מסומן להשלמה על ידיכם.

## דרישות טכניות

Python 3.10 ומעלה עם החבילות pandas, openpyxl, scipy, ו-pyreadstat לקריאת קובצי SPSS. ב-Claude כל אלה מותקנים או מותקנים אוטומטית בעת הצורך. מי שמריץ את הסקריפטים במחשב האישי יכול להתקין אותם בפקודה `pip install pandas openpyxl scipy pyreadstat`.

## מגבלות

הכלי מאתר בעיות ומציע פתרונות, אך הוא אינו מחליף שיקול דעת מחקרי. ההחלטות על הוצאת משיבים, על היפוך פריטים ועל הטיפול בערכים חסרים נשארות בידיכם, ויש לקבל אותן לפני שרואים את תוצאות הניתוח ולא בעקבותיהן. הכלי אינו מבצע ניתוח גורמים או בדיקת שקילות מדידה, ואינו מבין את משמעות הפריטים: את ניסוח הפריטים, ובמיוחד את הפריטים ההפוכים, יש לבדוק מול השאלון המקורי.


## לתורמים ולמפתחים

הבדיקות העצמיות רצות על נתונים סינתטיים בלבד ובודקות את שכבות האימות (כולל ארבעה ניסיונות חבלה מכוונים), את בדיקות המדידה ואיכות המענה, את נתוני החיישנים, את הנתונים הארגוניים ואת החוזה מול שלב הניתוח: `bash data-audit/tests/run_tests.sh`. שינוי בקוד מתקבל רק כאשר כל הבדיקות עוברות, ואזעקת שווא שבדיקה חושפת מתוקנת בקוד הבדיקה של הכלי ולא על ידי ריכוך הבדיקה. דיווחים על תקלות והצעות לשיפור יתקבלו בברכה דרך לשונית ה-Issues, אך מדובר בכלי לימודי שמתוחזק במסגרת עבודה אקדמית, ואין התחייבות לזמני מענה.
